Bienvenue !

Ce dashboard se protège avec une connexion Discord — seuls les comptes que tu autorises pourront y accéder. Il te faut une application Discord dédiée (gratuite, 1 minute à créer).

1
Va sur le Discord Developer Portal → New Application.
2
Onglet OAuth2 → copie le Client ID et génère/copie le Client Secret.
3
Toujours dans OAuth2 → Redirects, ajoute exactement l'URL pré-remplie ci-dessous, puis colle tes identifiants ici.

À coller identiquement dans "OAuth2 → Redirects" sur le Developer Portal.
